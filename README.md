# Connect-4 Game 🎮

This is a simple **Connect-4** game implemented in **C++**. It is a two-player command-line game where players take turns to drop their discs into a 7x6 grid, and the first to connect four in a row (horizontally, vertically, or diagonally) wins the game.

---

## 🛠️ How to Compile & Run

Make sure you have a C++ compiler like `g++` installed.

### Compile:

```bash
g++ connect-4.cpp -o connect-4
